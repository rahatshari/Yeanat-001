# পাঠামারা ইয়ানত সংরক্ষণ (Pathamara Eanat Sangrakkhan)

সংগঠনের সদস্যদের তথ্য সংরক্ষণ, মাসিক চাঁদা হিসাব, আয়-ব্যয় ব্যবস্থাপনা এবং রিপোর্ট তৈরির সম্পূর্ণ বাংলা ভাষার প্রোগ্রেসিভ ওয়েব ও মোবাইল অ্যাপ্লিকেশন (Android PWA)।

## 🚀 GitHub থেকে ক্লোন করে কম্পিউটারে চালানোর নিয়ম (How to Run Locally)

GitHub থেকে প্রজেক্টটি নামানোর পর নিচের সহজ ৩টি কমান্ড চালিয়ে এটি আপনার কম্পিউটারে রান করতে পারবেন:

### ১. কোড ক্লোন করুন
```bash
git clone https://github.com/আপনার-ইউজারনেম/আপনার-রিপো-নাম.git
cd আপনার-রিপো-নাম
```

### ২. প্রয়োজনীয় প্যাকেজ ইনস্টল করুন
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```

সার্ভার চালু হলে ব্রাউজারে যান:
👉 **`http://localhost:3000`**

## 🌐 GitHub Pages-এ সম্পূর্ণ বিনামূল্যে লাইভ হোস্ট করার নিয়ম

এই অ্যাপটিতে `vite.config.ts` এ `base: './'` কনফিগার করা আছে, যার ফলে GitHub Pages-এর সাব-ডিরেক্টরিতেও কোনো ফাইল মিসিং বা ব্ল্যাঙ্ক স্ক্রিন হবে না।

### পদ্ধতি ১: GitHub Actions এর মাধ্যমে স্বয়ংক্রিয় ডিপ্লয় (সবচেয়ে সহজ)
১. কোডটি আপনার GitHub রিপোজিটরির `main` ব্রাঞ্চে পুশ করুন।
২. আপনার রিপোজিটরির **Settings** -> **Pages** এ যান।
৩. **Build and deployment** সেকশনের **Source** ড্রপডাউনে **"GitHub Actions"** নির্বাচন করুন।
৪. ব্যাস! `.github/workflows/deploy.yml` ফাইলের কারণে কোড পুশ করার সাথে সাথে অ্যাপটি কয়েক সেকেন্ডে লাইভ হয়ে যাবে।

### পদ্ধতি ২: ম্যানুয়াল বিল্ড
```bash
npm run build
```
এটি `dist` ফোল্ডারে অপ্টিমাইজড প্রোডাকশন ফাইল তৈরি করবে, যা যেকোনো হোস্টিংয়ে সরাসরি আপলোড করা যাবে।

## 📦 অ্যান্ড্রয়েড APK ফাইল ডাউনলোড ও তৈরির নিয়ম (Android APK Download)

যদি আপনি ব্রাউজার ইনস্টলের পাশাপাশি সরাসরি `.apk` ফাইল ফোনে নামিয়ে ইনস্টল করতে চান বা হোয়াটসঅ্যাপে অন্যদের পাঠাতে চান, তবে নিচের সহজ ২টি উপায়ে APK পাবেন:

### পদ্ধতি ১: PWABuilder দিয়ে ১-ক্লিকে সরাসরি APK ডাউনলোড (Instant 1-Click APK)
১. আপনার অ্যাপের লাইভ লিংক কপি করুন (যেমন: GitHub Pages লিংক বা ক্লাউড লিংক)।
২. [PWABuilder.com](https://www.pwabuilder.com) ওয়েবসাইটে যান।
৩. বক্সে লিংকটি পেস্ট করে **"Start"** বাটনে চাপুন।
৪. **"Package for Stores"** সেকশন থেকে **Android (APK)** নির্বাচন করুন এবং **"Generate"** বাটনে ক্লিক করলেই সরাসরি আপনার ডিভাইসে সাইন করা `.apk` ফাইল ডাউনলোড হয়ে যাবে!

### পদ্ধতি ২: GitHub Actions দিয়ে স্বয়ংক্রিয় APK বিল্ড
এই রিপোজিটরিতে `.github/workflows/build-apk.yml` ফাইল সংযুক্ত আছে:
১. রিপোজিটরির **Actions** ট্যাবে যান।
২. বামপাশে **"Build Android APK"** সিলেক্ট করুন।
৩. **"Run workflow"** বাটনে ক্লিক করুন।
৪. বিল্ড সম্পন্ন হলে **Artifacts** থেকে **Pathamara-Android-APK** ডাউনলোড করে জিপটি আনজিপ করলেই ভেতরের `.apk` ফাইল পেয়ে যাবেন।

## 📱 অ্যান্ড্রয়েড মোবাইলে সরাসরি অ্যাপ হিসেবে ইনস্টল (PWA Direct Install)

১. মোবাইলের **Google Chrome** ব্রাউজারে অ্যাপটির লাইভ লিংকটি ওপেন করুন।
২. স্ক্রিনের উপরের ডানপাশে থাকা **৩-ডট (⋮)** মেনুতে চাপ দিন।
৩. মেনু থেকে **"Install app"** বা **"Add to Home screen"** (হোম স্ক্রিনে যোগ করুন) নির্বাচন করুন।
৪. "Install" চাপলে অ্যাপটি সরাসরি আপনার ফোনের অ্যাপ ড্রয়ারে ইনস্টল হয়ে যাবে। এটি সাধারণ অ্যান্ড্রয়েড অ্যাপের মতো অফলাইনেও কাজ করবে।
